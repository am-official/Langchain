# A18 · Feedback becomes a signal

Aggregate explicit user sentiment by topic and separate scored online feedback from exploratory Insights-style clustering.

Start with [INSTRUCTIONS](INSTRUCTIONS.md), then [EXPLANATION](EXPLANATION.md). Each project is self-contained; no imports from another lesson are required.

## What you will learn
- User sentiment as feedback
- Per-run evaluation versus aggregate insights
- Selection bias in feedback
