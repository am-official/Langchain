# Readiness checklist
- Verify the latest official study guide before relying on the provisional topic map.
- Complete all lesson sample contracts, failure tests, and exercises.
- Explain create_agent versus Deep Agents without memorizing tool names alone.
- Achieve at least 90% on each original 40-question mock on repeated attempts, separated by study time. A 90% threshold is a study target, not a guarantee of certification performance.
- Inspect domain/topic scores; revisit every missed question's project.
- Complete the LangSmith live practical assessment with redacted evidence.
- Explain authentication versus authorization, durability limits, and local simulation versus cloud deployment.
- Demonstrate a failed release gate and a successful checkpoint resume.

Mock scores alone do not establish exam readiness or production competence. Official coverage verification and live service checks remain separate requirements.
