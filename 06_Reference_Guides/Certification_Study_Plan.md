# Eight-week study plan
1. **Foundations:** B01–B10. Run each default, explain its imports and data flow, then complete its exercises. Do not treat a chain as an autonomous agent.
2. **Tools and evidence:** B11–B20. Inspect streaming, message trimming, tool IDs, safe arithmetic, chunk provenance, vector scores, citations, and trace privacy.
3. **Agent architecture:** I01–I10. Review actual graph state, middleware, runtime context, memory, approval interrupts, and PDF limitations.
4. **Evaluation:** I11–I20. Build datasets and experiments; compare code metrics and rubric judges; inspect human alignment.
5. **Production boundaries:** A01–A10. Compare planning/delegation, replay-safe checkpoints, restricted execution, retry policies, and deployment objects.
6. **Operations:** A11–A20. Demonstrate authorization failures, redaction, concurrency conflicts, stale-region refusal, trace analysis, monitoring, and alert deduplication.
7. **Capstones:** C01–C05. Complete independent acceptance criteria and add failure-path tests. Run optional service integrations only with your own non-sensitive learning data.
8. **Assessment:** Take all three original mocks without looking at the keys. Target repeated scores of at least 90%, analyze weak topics, and complete the LangSmith practical with live evidence.
